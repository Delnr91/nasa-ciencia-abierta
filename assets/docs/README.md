## Cómo leerlo

- Páginas 6–7: OSDMP.
- Páginas 10–13: gestión e intercambio de datos.
- Páginas 14–18: software.
- Páginas 24–25: apéndice B, plantilla de ejemplo.

El documento explica que es orientación y no establece por sí solo requisitos. Para una solicitud actual consulta la [página ROSES](https://science.nasa.gov/researchers/sara/faqs/OSDMP/) y la convocatoria concreta. No se presenta esta edición como la última o la aplicable a toda propuesta.

**Accesibilidad:** el PDF contiene texto extraíble y está marcado como etiquetado, según sus metadatos; eso no equivale a una auditoría completa. Se acompaña de explicaciones en español y una plantilla editable en Markdown.
