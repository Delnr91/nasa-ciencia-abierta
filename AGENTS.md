# Reglas para contribuir a este repositorio educativo

## Alcance

Repositorio independiente y público para estudiar dos cursos distintos: Open Science Essentials y Open Science 101. Español como idioma principal. No atribuir afiliación, certificación ni revisión académica externa inexistentes.

Trabajar directamente en GitHub cuando el usuario lo solicite. No crear checkouts, archivos locales, servicios ni sitios web para esta tarea. No tocar otros repositorios.

## Curso y lección correctos

Leer README.md, el índice del curso y la lección solicitada antes de editar. Mantener la estructura de Canvas que aporte el estudiante. No confundir lección de Essentials con módulo de Open Science 101. Trabajar una lección a la vez.

Cada lección: nombre español e inglés; resumen; imagen original explicativa con texto alternativo y explicación escrita; desarrollo; ejemplo genérico; práctica; preguntas originales con explicaciones desplegables; recursos con idioma/formato; procedencia y límites. Usar plantillas/LECCION.md como referencia adaptable, no como relleno obligatorio.

## Calidad y accesibilidad

Frases claras, acciones breves, iconos acompañados de palabras y jerarquía sencilla. Tablas pequeñas. Markdown compatible con GitHub; no depender de JavaScript ni afirmar que casillas o respuestas se guardan automáticamente.

Verificar afirmaciones nuevas con fuentes primarias. Distinguir contenido recibido, ampliación verificada y datos no contrastados. Las cifras de citas son asociaciones; una encuesta no es una tasa universal de estudios falsos. CO2 no demuestra vida. Corregir errores de traducción sin cambiar silenciosamente el sentido.

No trasladar información ni nombres de proyectos privados a contenido público. Las actividades deben ser genéricas o sintéticas. El futuro agente de aplicación de ciencia abierta a proyectos del usuario queda para después de completar la formación; no crearlo ni activarlo aquí.

## Progreso, fuentes y publicación

No marcar dominio, aprobación o certificado por tener apuntes. No acceder a sesiones privadas ni responder o enviar evaluaciones oficiales. Respetar derechos de terceros y la licencia del material original.

Comprobar enlaces internos, imágenes, navegación y ausencia de datos sensibles antes de publicar. Informar qué se verificó y qué no. Publicar únicamente cambios autorizados dentro del alcance.
