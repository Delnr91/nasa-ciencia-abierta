# Glosario · Español e inglés

[🏠 Inicio](README.md) · [Lección 1](cursos/open-science-essentials/lecciones/01-por-que-ciencia-abierta.md)

| Español | Inglés | En palabras sencillas |
|---|---|---|
| Ciencia abierta | Open science | Colaborar y compartir productos de investigación de manera responsable |
| Acceso abierto | Open access | Poder acceder a una publicación sin una barrera de pago para leerla |
| Datos abiertos | Open data | Datos disponibles con condiciones claras para reutilizarlos |
| Código abierto | Open-source software | Software con una licencia que permite usos y modificaciones establecidos |
| Reproducibilidad computacional | Computational reproducibility | Obtener resultados consistentes con los datos y el procedimiento originales |
| Replicabilidad | Replicability | Contrastar una pregunta mediante estudios con datos nuevos |
| Repositorio | Repository | Lugar organizado para almacenar y consultar materiales |
| Cita académica | Citation | Referencia que reconoce una fuente |
| Preprint | Preprint | Manuscrito difundido antes de revisión por pares; su estado debe indicarse |
| Retractación | Retraction | Retirada formal de una publicación del registro válido de resultados |
| Potencia estadística | Statistical power | Capacidad de una prueba para detectar un efecto especificado cuando existe |
| Informes selectivos | Selective reporting | Presentar solo una parte de los resultados y omitir otros relevantes |
| Contribuciones | Contributions | Trabajo concreto que aportó cada participante |
| Licencia | License | Condiciones que autorizan usos de un material |
| Acceso abierto diamante | Diamond open access | Modelo sin cobros de publicación a autores ni de lectura a lectores |

Las convenciones de reproducibilidad y replicabilidad siguen el [informe de las Academias Nacionales de 2019](https://www.nationalacademies.org/read/25303/chapter/2). Algunas disciplinas emplean esos términos de otra forma.

## Palabras de la lección 2

| Inglés | Español recomendado | Evita esta confusión |
|---|---|---|
| Scooping | Adelantarse a publicar un resultado | No equivale siempre a plagio |
| Sensitive data | Datos sensibles | No significa «datos frágiles» |
| Barriers | Barreras | No significa «barrios» |
| Controlled access | Acceso controlado | No equivale a acceso público |
| Misrepresentation | Tergiversación | Presentar de forma que distorsiona el sentido |
| Maintenance | Mantenimiento | Compartir no implica soporte perpetuo |
| Negative results | Resultados negativos | No apoyan un efecto esperado; no necesariamente prueban ausencia |
| DOI | Identificador de objeto digital | Identifica un objeto; no certifica su calidad |

## Palabras de la lección 3

| Sigla o término | Significado | Para recordarlo |
|---|---|---|
| OSDMP | Open Science and Data Management Plan | Plan de ciencia abierta y gestión de datos; no solo datos públicos |
| DMP | Data Management Plan | Plan de gestión de datos |
| SMP | Software Management Plan | Plan de gestión del software; no es el financiador |
| OSP | Open Science Plan | Plan de procesos, publicaciones y participación abierta |
| SMD | Science Mission Directorate | Dirección científica de NASA; distinta de SMP |
| FAIR | Findable, Accessible, Interoperable, Reusable | Encontrable, accesible, interoperable y reutilizable |
| Metadatos | Metadata | Información que describe y contextualiza un producto |
| Identificador persistente | Persistent identifier | Referencia estable a un producto o persona; no certifica su calidad |
| Procedencia | Provenance | Origen y transformaciones de los datos |
| Preregistro | Preregistration | Registro previo de un plan; no garantiza ausencia de errores |
