## Primera visita

1. Pulsa **Curso 1**.
2. Pulsa **Lección 1**.
3. Lee **En dos minutos**.
4. Mira la imagen y su explicación escrita.
5. Contesta una pregunta; después pulsa **Ver explicación**.

Un enlace abre otra página. El botón Atrás del navegador vuelve a la anterior. En cada lección también encontrarás enlaces para regresar.

## Elige tu manera de aprender

| Si prefieres… | Prueba esto |
|---|---|
| Texto breve | Resumen y tabla de ideas clave |
| Ver relaciones | Infografías y sus descripciones |
| Profundizar | Desarrollo y fuentes originales |
| Escuchar | Lectura en voz alta del dispositivo, si está disponible; no hay MP3 propios |
| Recordar activamente | Responde sin apuntes y luego compara |
| Inglés y español juntos | Consulta el glosario mientras lees Canvas |

Puedes ampliar el texto con el navegador. No dependas del color para entender los diagramas: cada elemento tiene texto y la explicación se repite por escrito. No se promete una certificación de accesibilidad ni compatibilidad auditada con todos los lectores de pantalla.

## Sesión breve sugerida

**Comprende una idea → explícasela a alguien → revisa lo que faltó.**

Las duraciones son personales. Leer más rápido no equivale a comprender mejor. Descansa cuando lo necesites.

## Tomar notas en la nube

Puedes usar notas personales de tu preferencia. Para editar un archivo del repositorio, el propietario puede abrirlo en GitHub y pulsar el lápiz; otros participantes pueden proponer cambios. Confirmar una edición la guarda en GitHub. Las listas de este material no actualizan Canvas.

**Evita poner datos personales en repositorios o Issues públicos.** Para una reflexión, basta un ejemplo genérico.
