# Cómo contribuir

[Inicio](README.md)

Puedes proponer una corrección desde **Issues** o editar un archivo y enviar una propuesta de cambio. No hace falta aportar código: explicar qué frase no se entiende ya ayuda.

## Una propuesta útil incluye

1. Página o lección.
2. Fragmento que conviene mejorar.
3. Explicación del problema.
4. Fuente original, si corriges un dato.
5. Alternativa en español claro.

Para una imagen, añade texto alternativo y una explicación equivalente. Para un recurso, indica idioma, formato, coste conocido y utilidad. No inventes horas, certificaciones, afiliaciones ni disponibilidad.

Las preguntas de práctica deben ser originales, con respuesta razonada. No publiques contenido de evaluaciones oficiales, datos personales o información de proyectos privados. Publicar un repositorio no equivale a aprobar un curso.

Los aportes originales se integran bajo la [licencia del repositorio](LICENSE.md); no copies materiales incompatibles de terceros.
