## Qué pide Canvas para completar

- Las páginas del módulo principal deben marcarse como hechas.
- El examen vale **12 puntos**.
- El requisito mostrado es **al menos 9 de 12 puntos (75 %)**.
- La introducción aparece como opcional.

El estado real y cualquier cambio de requisitos se comprueban en tu cuenta de Canvas. Este repositorio no marca páginas como hechas ni envía respuestas.

## Ruta de estudio sugerida

1. Abre la [lección 1](lecciones/01-por-que-ciencia-abierta.md).
2. Explica la idea central con tus palabras.
3. Responde las preguntas antes de abrir las soluciones.
4. Completa una reflexión basada en un ejemplo genérico.
5. Vuelve a Canvas para continuar la lección correspondiente.

**Progreso:** disponer del material no demuestra que lo hayas aprendido. La lección 5 se preparará cuando se comparta su contenido; no hay enlaces falsos a páginas todavía inexistentes.
